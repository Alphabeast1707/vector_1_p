Detailed Engineering & Mathematical Mapping Guide

1 Data Contracts & Schemas schemas/shared_db_schemas.py

Why It Matters: Establishes a highly resilient, self-documenting JSON contract. This prevents corrupted or empty values from propagating into GPyTorch, Scipy or PyTorch layers which would throw fatal execution errors.

ProfileCard (Class)

Stores raw API chemical and thermal profiles (e.g., glass transition temperature: glass_transition_temp_c).

Excipient (Class)

Strictly validates formulation excipient limits (e.g., concentration ranges, excipient_tg_c, moisture_stability).

StrategyCard (Class)

The core aggregator. Binds the chosen API profile, excipient matrix, target hardware, and mechanical ranges.

CQATargets (Class)

Specifies optimization target bounds for Critical Quality Attributes (e.g., targeted dissolution curves, hardness limits).

2 Dynamic Search Space Warping engines/domain_builder.py

Why It Matters: Instead of executing calculations over a standard fixed geometric cube, the system dynamically shrinks the valid process ranges. This protects the formulations from degradation (e.g., excessive drying temperature collapsing an excipient).

build_domain (Function)

• Audits moisture sensitivity: If excipient moisture stability is weak (< 0.5), limits drying chamber moisture ceilings to 5.5%. If excipients are highly water-loving (hydrophilicity > 0.8), raises moisture floor to 4.0%.
• Thermal capping: Automatically caps drying temp at 5.0°C below the lowest glass transition (Tg) of the matrix.

3 Weibull Dissolution Curve-Fitting engines/dissolution_weibull.py

Why It Matters: Time-series curves have high dimensional coordinate spacing (6–12 discrete time points) which are inefficient to fit in Gaussian processes. This model compresses curve kinetics down to just two mathematically distinct variables ($\eta, \beta$).

Formula: F(t) = F_infinity * (1 - exp( - (t / η)^β ))
weibull_model (Function)

Evaluates cumulative Weibull curves based on time ($t$), scale ($\eta$), and shape ($\beta$).

fit_weibull_profile (Function)

Uses scipy.optimize.curve_fit with Levenberg-Marquardt to extract ($\eta, \beta$) from raw historical data.

4 Gaussian Process Surrogates engines/gp_model.py

Why It Matters: Formulates high-fidelity non-linear predictions from sparse formulation data. By outputting explicit variances alongside mean estimates, it guides the acquisition layer where uncertainty is highest.

SingleTaskGP (Class)

Instantiates a coregionalized multi-output Gaussian Process model mapping input space $X$ to objective responses $Y$.

MaternKernel (nu=2.5)

Enforces Matérn 5/2 covariance with Automatic Relevance Determination (ARD) to learn dimensional lengthscales.

fit_gpytorch_mll (Function)

Maximizes the Marginal Log-Likelihood (MLL) using L-BFGS-B to tune surrogate hyperparameters.

5 Multi-Objective Bayesian Optimization Loop engines/bo_loop.py

Why It Matters: Finds optimal formulations balancing conflicting objectives. Uses physical and operational parameters, optimizing safely inside valid excipient blending limits.

Acquisition: α_qLogNEHVI(X) = E[ log( HV(F(X U X_obs)) \ HV(F(X_obs)) ) ]
SobolQMCNormalSampler

Targeted quasi-Monte Carlo sampler restricted to sample_shape=16. Drastically slashes runtimes from 40s to under 9s.

optimize_acqf (Function)

Optimizes the acquisition surface using the L-BFGS-B gradient-based algorithm.

Linear Constraints (Structure)

Enforces the matrix formulation limit directly inside the solver: excipient concentration sums must not exceed 70%.

6 Dimensionless Scale-Up Physics engines/scaleup_physics.py

Why It Matters: Automatically maps lab-scale process optimizations directly to commercial manufacturing dimensions without carrying out raw, expensive visual trials.

Froude Speed scaling: N_pilot = N_lab * ( 1 / scale_factor )^0.5
compute_scaleup_metrics (Function)

• Calculates pilot speed by keeping Froude number constant (preserving shear/gravitational forces).
• Generates parallel Constant Tip Speed metrics ($\pi N D$) to check upper shear boundaries and output compromise pilot speed bounds.

7 Stateless Orchestration Layer routers/v1_bayesian_doe.py

Why It Matters: Central control node. Exposes complex scientific engines cleanly via a single, stateless HTTP POST interface that isolates mathematical execution from client view rendering.

POST /active-learning (Endpoint Handler)

1. Ingests raw client data templates.
2. Converts historical curves to Weibull scale parameters.
3. Constrains and warps boundaries.
4. Triggers GP fit and acquisition search.
5. Computes physical equipment scale-up speed translations.
6. Outputs recommended variables and diagnostic Pareto arrays back to client dashboards.

8 API Gateway Setup main.py

Why It Matters: Bootstraps and configures the FastAPI runtime container, mounting CORS middleware layers allowing frontends (Port 5173) to securely read mathematical routers (Port 8001).

9 CI Pipeline & Local Verification .github/workflows/ci.yml / verify_build.py

Why It Matters: Protects production branches. Local verification (verify_build.py) ensures all math packages execute correctly in dev work environments. GitHub actions (ci.yml) runs comprehensive lint/unit/integration coverage validation sequentially prior to merging.
